# Project Implementation Office (PIO) - PHLCEP Swabi

Official Digital Record Management & Project Management Hub for Pehur High Level Canal Extension Project (PHLCEP) Swabi, Khyber Pakhtunkhwa.

## Features
- **Corporate Authentication**: Secured via Clerk with role-based staff access and corporate branding.
- **Role-Based Permissions**: Admin-exclusive document deletion controls (`pio_admin`). Staff users can view and download.
- **Supabase Cloud Storage**: Fast, centralized, direct cloud storage for drawings, contracts, variation orders, and official correspondence.
- **Package Categorization**: Organized workspace for all 8 project packages (PKG-01 to PKG-04, RLL, Demo Plots, and more).
- **Responsive Interface**: Native desktop tables and mobile record card views.

## Running Locally
```bash
npm install
npm start
```
Default local port: `http://localhost:8080`
